# Akshitha-Voice-AI-Voice-Powered-YouTube-Assistant

An AI-powered Voice Assistant built using Python and Streamlit that listens to user commands and plays songs directly on YouTube using voice input.

## 🚀 Project Overview

Speak2Play is a simple yet powerful AI Voice Assistant that demonstrates:

🎙 Speech-to-Text processing

🔊 Text-to-Speech response generation

▶ YouTube automation

## 🌐 Interactive web app using Streamlit

The assistant listens to a voice command like:

"Play Believer"

And automatically plays the requested song on YouTube.

## 🛠 Tech Stack

Python

Streamlit

SpeechRecognition

gTTS (Google Text-to-Speech)

PyWhatKit

The app will open in your browser.

## 🌍 Deployment

This project can be deployed on:

Streamlit Community Cloud (Text-based version recommended)

Local system (Full microphone support)

⚠ Note: Microphone input may not work on cloud deployment due to server hardware limitations.

✔ Voice command recognition

✔ Automatic YouTube song playback

✔ AI-generated voice response

✔ Interactive Streamlit UI
